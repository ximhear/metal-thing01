# Metal 기반 "정말 쓸모있는" macOS 앱 — 브레인스토밍

- 날짜: 2026-11-15
- 주제: GPU(Metal)를 써야만 제대로 되는, 일상·업무에서 실제로 쓸 macOS 앱
- 가정: macOS 14+ Apple silicon, SwiftUI + Metal, 1인 개발, 첫 버전 1~2주

## 4. 추천

1. **천만 점 플로터 (가칭 "Scatter")** — 가장 "쓸모있음 + Metal이 꼭 필요함"이 겹치는 아이디어.
   - 1~2일 프로토타입: CSV에서 숫자 열 두 개를 골라 `MTLBuffer`에 올리고, point primitive + 가산 블렌딩(밀도 표현)으로 그리기. 트랙패드 확대·이동을 60fps로 유지하는지, 천만 점에서 확인.
2. **픽셀 비교기** — 가장 빨리 완성도 높게 낼 수 있는 아이디어.
3. **색각 시뮬레이터** — 독창성과 실용성이 좋음. 권한 흐름이 부담.
