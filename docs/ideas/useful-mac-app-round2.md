# 쓸모있는 macOS 앱 — 브레인스토밍 2차

- 날짜: 2026-11-15
- 바뀐 조건: Metal은 필수가 아님(필요할 때만). 1순위 기준은 **"매주 실제로 열까"**. MVP는 하루 안에.
- 1차 결과: Scatter(천만 점 플로터)는 성능 목표를 달성했지만 쓸 곳이 분명하지 않아 보류. 코드는 `Scatter/`에 남겨 둠.
- 가정: 사용자는 Mac에서 Swift·Claude Code·터미널(Warp)을 쓰는 한국어 사용 개발자.
